# Remit North public site and tables feed

Copied to the root of the public repository `sohi666/remit-north-info` and served by GitHub Pages at
https://sohi666.github.io/remit-north-info/ (French at the root, English under `en/`).

- `index.html`, `en/index.html`: support and marketing URLs (store listings)
- `privacy.html`, `en/privacy.html`: privacy policy URLs (App Store Connect, Play Console)
- `terms.html`, `en/terms.html`: terms of use
- `tables/index.json` + `tables/<year>-<version>.json`: the tax tables the app downloads. Generated by
  `node scripts/publish-tables.mjs` from `src/tax/packs/`; the "Publish tables" workflow pushes them.
